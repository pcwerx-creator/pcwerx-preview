# PC Werx site preview

Private design preview of the new PC Werx site (all pages). This is **not** the live site at pcwerx.ca.

- Served under `/pcwerx-preview/`. Static export of the private working copy (generated by `new-site/tools/static-export.py`).
- Hidden from search (`noindex, nofollow` on every page and `robots.txt` disallows all crawlers).
- Phone buttons dial 905-572-9379. Forms are disabled in this preview (they show an email/call notice instead).
- The "Ask PC Werx" chat cannot look up answers here; it falls back to "please call".

Do not point a custom domain or DNS at this repository.
